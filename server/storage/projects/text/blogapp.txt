Dondon & Nini’s Blog is a full-stack blog platform I built using the React ecosystem on the frontend and Node.js with Express on the backend. The app features a clean, themed UI with custom-styled components, login/logout functionality using persistent cookies, post creation with image uploads, and dynamic rendering of blog content in paragraph-style formatting. The goal of the project was to simulate a real-world blogging platform, from both a UI/UX and technical infrastructure standpoint.

Users can log in via a sidebar popup, which authenticates through a backend API and stores a session cookie using react-cookie. Upon login, they gain access to administrative tools, such as a post submission form where they can input a post title, full-paragraph blog content (with newlines, indents, etc.), and upload a thumbnail image. These posts are stored in a SQLite3 database and rendered dynamically across the site. Admins also have the ability to delete posts, with the backend simultaneously removing associated images from the server’s file system.

The app is structured with React Router for seamless navigation between Home, About, and Contact pages. The entire project was styled from scratch using CSS, with extra attention paid to theming, animation, and mobile responsiveness. Popup behavior for the login modal was handled using reactjs-popup, and image uploads were managed using FormData and multipart/form-data requests to Express routes. The backend also includes logic for handling user authentication, post creation, and media cleanup.

This project allowed me to deepen my skills in full-stack development, particularly around form handling, cookie/session logic, secure route building, and state management in React. It serves as both a personal project and a template for future blog-based or content management platforms I may build.
