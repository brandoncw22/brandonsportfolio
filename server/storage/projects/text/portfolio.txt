This portfolio website was built to showcase my skills, projects, and professional background as a Computer Science student. It serves as a central hub for my work, highlighting my passion for full-stack and web development with a clean, responsive design.

The frontend is developed with React.js, while the backend is powered by Node.js/Express and a SQLite3 database. It features dynamic sections such as a gallery that pulls images directly from the database, a projects showcase with expandable cards and image slideshows, and a contact form fully integrated with the backend API.

Beyond functionality, the site also emphasizes design with animated gradients, interactive elements, and a modular layout. This project demonstrates my ability to build a complete, database-driven web application from scratch while continuously improving and iterating on the design and features.
